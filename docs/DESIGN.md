# learn-gis — 设计规范（Design）

> v2 · 品牌蓝紫视觉体系 · 移动优先（≤640px 第一设计目标），桌面全宽 + 224px 侧栏。

---

## 1. 设计原则

1. **拇指优先**：移动端主操作固定在底部（悬浮胶囊 tab / 粘性操作条），单个 tab ≥ 44px 触控高度。
2. **选中必须可见**：导航四项一视同仁——未选中中性灰，选中才用品牌色 + 淡底胶囊（底 tab / 侧栏一致）；不为任何一项铺渐变底座或实心底。
3. **桌面全宽**：不设 `max-width` 容器，内容用满侧栏以外的区域；仅正文段落限制可读行长。
4. **先解释、后结论**：答错先给被选中干扰项的针对性解释，再给正确答案与解析。
5. **层级分明**：主标题 32–40 / 模块标题 20–24 / 正文 14–16 / 辅助 12–13，禁止整站同字号。
6. **无 JS 可读**：讲义是 MDX 静态渲染；重型依赖（地图）只动态加载。

## 2. 品牌令牌（`app/globals.css`）

| 类别 | 令牌 | 值 |

| 画布 | `background` | `#F5F6FF` |
| 卡片 | `card` | `#FFFFFF` |

| 文字 | `foreground` / `-secondary` / `-tertiary` / `-muted` | `#171A35` / `#59617E` / `#8188A5` / `#A2A9C0` |
| 边框 | `border` / `-strong` | `#E5E8F5` / `#D5DAEC` |

状态色在亮色模式下取「可作正文的深色变体」（对比度 ≥ 4.5:1），暗色模式自动提亮。

### 2.1 品牌图标

- 唯一源图：`scripts/assets/gis-logo.png`（白底、144×144）。`npm run icons` 去底 → 按图形边界裁切 → 导出全部尺寸；产物入库，日常不需要重跑。
- 产物：`app/favicon.ico`（16/32/48）、`app/icon.png`（256）、`app/apple-icon.png`（180）、`public/brand/logo.png`（128，站内用）。
- 图形自带 squircle 轮廓，四角是**真透明**：UI 里直接用圆角图，不要再套 `rounded-*` / 渐变底 / 边框，否则会出现双圆角或白边。
- 站内尺寸：移动端顶栏 `32×32`、桌面侧栏 `36×36`，走 `next/image` 静态导入（自动 2x）；品牌名是文字，图片 `alt=""` 作装饰。

## 3. 字体与排版

- 字体：`Inter Variable`（本地打包，`@fontsource-variable/inter`）+ 系统中文字体（PingFang SC / Microsoft YaHei / Noto Sans SC）。
- 标题字重 600，字距 `-0.01em ~ -0.02em`；正文 1.75–1.85 行高。
- 数字统一 `tabular-nums`（进度、得分、题号、题量）。

| 正文 | 15–16px | 15–16px |

## 5. 布局

```
桌面 (≥1024)                移动 (<1024)
┌──────┬────────────────┐   ┌────────────────┐
│ 224  │  Topbar? 无      │   │  顶栏 品牌+主题 │
│ 侧栏 │  内容全宽 32px   │   ├────────────────┤
│ 固定 │  Hero / 列表     │   │  内容 16px      │
│      │  底部 footer     │   ├────────────────┤
└──────┴────────────────┘   │ 悬浮 tab（52px 胶囊）│
                            └────────────────┘
```

- 桌面不设最大宽度：内容区 = 视口 − 224px，左右各 32px 内边距。
- 列表在 `md` 两列、`xl` 三列铺满。
- 讲义页：`1fr + 18rem` 两栏，右侧「本章」卡片 `sticky top-8`；正文 `max-w-3xl` 保可读行长。
- 移动端：单列；底部 tab 是**悬浮胶囊**（`max-w-md` 居中、1.75rem 圆角、`bg-card/90` + 毛玻璃 + 柔和阴影，无上边框），两侧与底部各留 16px / 0.6rem + 安全区；答题页隐藏，只留粘性「提交 / 下一题」。
- 移动端导航四项：**首页 / 学习 / 考试 / 设置**；四项结构完全一致（18px 图标 + 11px 文字、无图标底座），颜色只区分选中/未选中。复习、进度等次级入口收进 `/settings`，并在首页的「快捷入口」复述一遍（首页只做介绍 / 统计 / 入口，不铺章节列表）；「考试」落 `/exam`（选卷开考），不动讲义与答题页。

## 6. 组件规则

| 组件 | 移动端 | 桌面端 |
|---|---|---|
| 主导航 | 悬浮胶囊 tab（4 项：首页 / 学习 / 考试 / 设置），当前项：淡底胶囊 + 品牌色；未选中：中性灰、无底色 | 224px 侧栏，当前项：**淡底胶囊 + 品牌色**；未选中：`foreground-secondary` |
| 答题操作 | 粘性底条，48px 全宽渐变按钮 | 行内右对齐 |
| 选项 | 全宽、≥48px、8px 圆角；选中：品牌描边 + 淡底 | 同左，右侧显示数字快捷键 |
| 判卷反馈 | 正确项绿描边/绿底 + ✓；错选红描边/红底 + ✗；解答/解析/参考三段 | 同左 |
| 结果页 | 掌握度圆环（<80% 品牌色，≥80% 绿色）+ 错题卡 | 同左 |
| 卡片 | 14px 圆角 + 卡片阴影，白底 | 同左 |

## 7. 断点

| 断点 | 变化 |
|---|---|
| `<640` | 单列、悬浮胶囊 tab、粘性操作条、全宽按钮、表格横向滚动 |
| `≥640` | 按钮改行内、卡片两列（`md`） |
| `≥1024` | 侧边栏出现、顶部导航消失、内容全宽、讲义右侧栅格、答题操作条回行内 |
| `≥1280` | 章节/进度卡片三列 |

