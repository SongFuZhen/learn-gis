# learn-gis — 设计规范（Design）

> v2 · 品牌蓝紫视觉体系 · 移动优先（≤640px 第一设计目标），桌面全宽 + 224px 侧栏。

---

## 1. 设计原则

1. **拇指优先**：移动端主操作固定在底部（粘性操作条 / 底部 tab），高度 ≥ 48px。
2. **选中必须可见**：导航当前项用品牌渐变实心高亮（侧栏）/ 渐变顶部指示条 + 品牌色（底 tab）。
3. **桌面全宽**：不设 `max-width` 容器，内容用满侧栏以外的区域；仅正文段落限制可读行长。
4. **先解释、后结论**：答错先给被选中干扰项的针对性解释，再给正确答案与解析。
5. **层级分明**：主标题 32–40 / 模块标题 20–24 / 正文 14–16 / 辅助 12–13，禁止整站同字号。
6. **无 JS 可读**：讲义是 MDX 静态渲染；重型依赖（地图）只动态加载。

## 2. 品牌令牌（`app/globals.css`）

| 类别 | 令牌 | 值 |
|---|---|---|
| 品牌主色 | `brand` | `#625BFF` |
| 悬停 | `brand-hover` | `#5148ED` |
| 渐变 | `--brand-gradient` | `125deg, #397BFF → #625BFF 48% → #984DFF` |
| 辅助色 | `brand-violet` / `brand-cyan` / `brand-gold` | `#8B4DFF` / `#35CFF2` / `#FFCA61` |
| 画布 | `background` | `#F5F6FF` |
| 卡片 | `card` | `#FFFFFF` |
| 悬浮 | `background-hover` | `#F0F1FF` |
| 文字 | `foreground` / `-secondary` / `-tertiary` / `-muted` | `#171A35` / `#59617E` / `#8188A5` / `#A2A9C0` |
| 边框 | `border` / `-strong` | `#E5E8F5` / `#D5DAEC` |
| 状态 | `success` / `warning` / `destructive` / `info` | `#0A7D5C` / `#B7791F` / `#D92D4F` / `#397BFF` |
| 品牌淡底 | `brand-soft` | `#EEF0FF` |

状态色在亮色模式下取「可作正文的深色变体」（对比度 ≥ 4.5:1），暗色模式自动提亮。
渐变只用于**主操作按钮、选中态、进度条、品牌光晕**，不用于大面积背景。

## 3. 字体与排版

- 字体：`Inter Variable`（本地打包，`@fontsource-variable/inter`）+ 系统中文字体（PingFang SC / Microsoft YaHei / Noto Sans SC）。
- 标题字重 600，字距 `-0.01em ~ -0.02em`；正文 1.75–1.85 行高。
- 数字统一 `tabular-nums`（进度、得分、题号、题量）。

| 层级 | 移动 | 桌面 |
|---|---|---|
| 页面主标题 | 26–28px | 32–40px |
| 区块/模块标题 | 20px | 22–24px |
| 卡片标题 | 15px | 15px |
| 正文 | 15–16px | 15–16px |
| 辅助信息 | 11–13px | 12–13px |

## 5. 布局

```
桌面 (≥1024)                移动 (<1024)
┌──────┬────────────────┐   ┌────────────────┐
│ 224  │  Topbar? 无      │   │  顶栏 品牌+主题 │
│ 侧栏 │  内容全宽 32px   │   ├────────────────┤
│ 固定 │  Hero / 列表     │   │  内容 16px      │
│      │  底部 footer     │   ├────────────────┤
└──────┴────────────────┘   │  底部 tab 64px  │
                            └────────────────┘
```

- 桌面不设最大宽度：内容区 = 视口 − 224px，左右各 32px 内边距。
- 列表在 `md` 两列、`xl` 三列铺满。
- 讲义页：`1fr + 18rem` 两栏，右侧「本章」卡片 `sticky top-8`；正文 `max-w-3xl` 保可读行长。
- 移动端：单列；底部 tab 隐藏于答题页，答题页只留粘性「提交 / 下一题」。

## 6. 组件规则

| 组件 | 移动端 | 桌面端 |
|---|---|---|
| 主导航 | 底部 tab（4 项，64px + 安全区），当前项：渐变顶条 + 品牌色 + 淡底胶囊 | 224px 侧栏，当前项：**品牌渐变实心 + 白字 + 品牌阴影** |
| 答题操作 | 粘性底条，48px 全宽渐变按钮 | 行内右对齐 |
| 选项 | 全宽、≥48px、8px 圆角；选中：品牌描边 + 淡底 | 同左，右侧显示数字快捷键 |
| 判卷反馈 | 正确项绿描边/绿底 + ✓；错选红描边/红底 + ✗；解答/解析/参考三段 | 同左 |
| 结果页 | 掌握度圆环（<80% 品牌色，≥80% 绿色）+ 错题卡 | 同左 |
| 卡片 | 14px 圆角 + 卡片阴影，白底 | 同左 |

## 7. 断点

| 断点 | 变化 |
|---|---|
| `<640` | 单列、底部 tab、粘性操作条、全宽按钮、表格横向滚动 |
| `≥640` | 按钮改行内、卡片两列（`md`） |
| `≥1024` | 侧边栏出现、顶部导航消失、内容全宽、讲义右侧栅格、答题操作条回行内 |
| `≥1280` | 章节/进度卡片三列 |

## 8. 验收

```bash
npm run build            # 全静态
npm run check:overflow   # 320/375/390 无横向溢出（表格内部滚动不算）
npm run smoke:quiz       # 真实 Chrome，6 章 85 题全对，零 console 错误
```

M5 目标：Lighthouse ≥ 95、暗色模式对比度 ≥ 4.5:1、键盘全流程可达（数字键选、Enter 提交/继续）。
