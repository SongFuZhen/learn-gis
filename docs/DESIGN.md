# learn-gis — 设计规范（Design）

> v1 · 移动优先（≤640px 为第一设计目标），桌面端只做增强。
> 令牌沿用 `F:/Codes/Products/ink_template` 的命名（墨 #20252B / 纸 #FFFDF8 / 金 #C8953E / 青黛 #3E6870）。

---

## 1. 设计原则

1. **拇指优先**：主操作固定在移动端底部（粘性操作条 / 底部 tab），高度 ≥ 48px。
2. **一屏一件事**：答题页一题一屏，底部 tab 隐藏，只留「提交 / 下一题」。
3. **先解释、后结论**：答错先给被选中干扰项的针对性解释，再给正确答案与解析。
4. **可读优先于装饰**：正文 16px、行高 1.8；不用纯白/纯黑大色块，用极轻暖调渐变。
5. **无 JS 可读**：讲义是 MDX 静态渲染，禁用首屏以外的重型依赖（地图仅在 M4 动态加载）。

## 2. 令牌（`app/globals.css`）

| 类别 | 令牌 | 用途 |
|---|---|---|
| 背景 | `background` / `-subtle` / `-muted` | 页面底、分区底 |
| 卡片 | `surface` / `-raised` / `-hover` | 卡片、选项、悬浮态 |
| 文本 | `foreground` / `-secondary` / `-tertiary` / `-muted` / `-disabled` | 四级文字层次 |
| 品牌 | `accent`(#C8953E) / `accent-hover` | 唯一「主操作」色：开始、提交、下一题 |
| 语义 | `success` / `warning` / `destructive` / `info` | 判卷、提示、引用链接 |
| 边框 | `border` / `-subtle` / `-strong` | 默认、分隔、可交互描边 |

暗色模式由 `.dark` 覆盖同名令牌，`next-themes` 的 `attribute="class"` 切换；两套令牌都只改值不改名。

## 3. 排版

- 页面标题：移动 22px / 桌面 30~36px，`tracking-tight`。
- 卡片标题：15px semibold；正文 13~15px，说明文字 11~13px。
- 讲义正文 16px / 1.8；`h2` 左侧 3px 金色竖条；`blockquote` 金色淡底。
- 表格：`white-space: normal` + 自动换行，390px 内三列可读（不依赖横向滚动）。
- 数字统一 `tabular-nums`（进度、得分、题号）。

## 4. 间距与圆角

- 页面栅格：`max-w-content`(1080px) + `px-4`（移动）/ `px-6`（≥640px）。
- 卡片内边距 16px（移动）/ 24px（≥640px）；卡片间距 8px，区块间距 24~32px。
- 圆角：按钮/卡片 8px(`rounded-lg`)，大卡片 12px(`rounded-xl`)，小徽标 4px。

## 5. 组件规则

| 组件 | 移动端 | 桌面端 |
|---|---|---|
| 导航 | 底部固定 tab（4 项，高 56px + 安全区），答题页隐藏 | 顶部导航 |
| 答题操作 | 粘性底条，按钮全宽 48px | 行内右对齐按钮 |
| 选项 | 全宽、≥48px、字母键位块 | 同上，右侧显示数字快捷键 |
| 判卷反馈 | 正确项标绿 + ✓、错选项标红 + ✗、解析与引用 | 同左（宽度收敛在 1080 内） |
| 结果页 | 掌握度圆环 + 错题卡 | 圆环与文字左右并排 |

## 6. 断点

| 断点 | 变化 |
|---|---|
| 默认（<640px） | 单列、底部 tab、粘性操作条、全宽按钮 |
| `sm` ≥640px | 顶部导航、按钮改行内、多列卡片 |
| `lg` ≥1024px | 讲义页出现右侧「本章」栅格（开始测验 + 题量） |

## 7. 验收

```bash
npm run build            # 页面全静态
npm run check:overflow   # 320/375/390 三档无横向滚动
npm run smoke:quiz       # 真实 Chrome 走完一章，零 console 错误
```

M5 目标：Lighthouse ≥ 95、深色模式对比度 ≥ 4.5:1、键盘全流程可达（数字键选、Enter 提交/继续）。
