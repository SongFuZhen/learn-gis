## 本章你会学到

3D Tiles 的格式概念（tileset.json、瓦片树、LOD/SSE）；`Cesium3DTileset.fromUrl` 的标准挂载流程；用 `Cesium3DTileStyle` 按属性给模型上色；以及 token-free 的实操路径——用 CesiumJS 自带样例 tileset 本地跑通全流程。

## 1. 格式概念：三维版的瓦片金字塔

[GIS 课第 8 章](/s/gis/07) 的影像金字塔把"一张全球地图"切成小方格；3D Tiles 把"一个巨大的三维模型/海量模型"切成带空间索引的瓦片树：

```text
tileset.json ──── 根：描述整棵树的空间范围与子节点
 ├─ tile (b3dm/glb/i3dm/pnts)   一个瓦片 = 一批三角面 + 元数据
 ├─ tile ...                     每个瓦片记录自己的包围盒与子瓦片
 └─ ...                          相机看到哪、哪个瓦片细节够，就加载哪块
```

- **tileset.json**：入口文件，描述瓦片树的层级、包围盒、几何误差（geometric error）。
- **瓦片内容**：b3dm（批量三维模型，最常见的建筑块）、glb（glTF 模型）、i3dm（实例化模型，如成千上万的树）、pnts（点云）。
- **LOD 驱动**：每层瓦片带"几何误差"——相机越近要求精度越高，引擎据此决定加载/卸载哪层。思想与影像金字塔完全同构，只是从 2D 方格变成了 3D 包围盒树。

常见的 3D Tiles 来源：倾斜摄影（无人机航拍建模）、BIM/CIM 导出、城市白模批量生成、点云切片。

## 2. 挂载：两步走

```js
// ① 创建 tileset（异步：要请求 tileset.json）
const tileset = await Cesium.Cesium3DTileset.fromUrl(
  "http://localhost:8000/tileset.json",
  { maximumScreenSpaceError: 16 }   // 精度开关，默认 16（第 09 章细讲）
);

// ② 挂进场景
viewer.scene.primitives.add(tileset);
// 老写法（1.104 前）：new Cesium.Cesium3DTileset({ url: "..." })，已废弃

// 定位到模型
await viewer.zoomTo(tileset);
```

注意挂载点不同：影像进 `imageryLayers`，实体进 `entities`，**3D Tiles 进 `scene.primitives`**——它是渲染原语层的东西，这是三套数据三种容器的又一次体现（第 02 章的双层模型 + 本章 = Cesium 数据全家桶）。

<Callout type="warn" title="ion 数据集需要 token（本课只认不点）">
你见过最多的 3D Tiles 演示——OSM Buildings（`Cesium3DTileset.fromIonAssetId(96188)`）、Google Photorealistic 3D Tiles——都是 **ion 托管服务，需要 token**。OSM 建筑数据本身开源（© OpenStreetMap 贡献者），但 ion 的托管分发是商业服务。本课程的实操全部走「自托管 tileset」路径：数据在你手里，token 与你无关。
</Callout>

## 3. token-free 实操：本地跑通 Cesium 官方样例

CesiumJS 仓库自带样例 tileset（`Apps/SampleData/Cesium3DTiles/`），不用 ion 也能全流程体验：

```bash
# 1. 下载 CesiumJS 仓库（或只取 SampleData 目录）
git clone --depth 1 https://github.com/CesiumGS/cesium.git

# 2. 起一个静态文件服务器
npx serve cesium/Apps/SampleData/Cesium3DTiles/Tilesets/Tileset

# 3. 记下地址（如 http://localhost:3000/tileset.json），挂进你的场景
```

```js
const tileset = await Cesium.Cesium3DTileset.fromUrl(
  "http://localhost:3000/tileset.json"
);
viewer.scene.primitives.add(tileset);
await viewer.zoomTo(tileset);
```

这就是生产环境的完整缩影：**任何自托管（或 CDN 托管）的 tileset.json 都是这么接的**——换 URL 而已。公司里接的倾斜摄影、BIM 导出件，走的都是这条路。

## 4. Cesium3DTileStyle：按属性给模型上色

3D Tiles 的每个瓦片可以带**批表（batch table）属性**——比如每栋楼的高度、楼龄、用途。用 `Cesium3DTileStyle` 可以像 CSS 一样按条件染色：

```js
tileset.style = new Cesium.Cesium3DTileStyle({
  // 按 batch table 属性 ${height} 分级染色
  color: "${height} > 100 ? color('red') : color('skyblue')",
});
```

风格表达式里 `${...}` 引用属性，支持条件、函数、透明度——相当于 [GIS 课第 7 章](/s/gis/06) 制图分级的"三维版"。这让同一份城市白模不重做数据就能表达主题地图（人口密度、噪声、日照……）。

<Callout type="must" title="必背 · 3D Tiles 三条">
1. tileset.json 是入口：瓦片树 + 几何误差 + 包围盒；b3dm/glb/i3dm/pnts 是瓦片内容
2. 挂载两步：`Cesium3DTileset.fromUrl(url)` → `viewer.scene.primitives.add(tileset)`
3. ion 托管数据集要 token；自托管 tileset 是 token-free 的正路
</Callout>

## 5. 本章小结

- 3D Tiles = 三维模型的瓦片金字塔标准：tileset.json 入口 + b3dm/glb/i3dm/pnts 内容 + LOD 树。
- 挂载走 `scene.primitives`（与影像/实体不同容器）。
- `Cesium3DTileStyle` 按批表属性条件染色——三维版专题地图。
- OSM Buildings/Google 影像在 ion 上需要 token；自托管 tileset 免 token 且流程完全一致。
