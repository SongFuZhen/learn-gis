1. Entity = 声明式对象：`viewer.entities.add({...})`，一个 entity 可同时挂 point + label + billboard
2. GeoJSON 整包加载用 `GeoJsonDataSource.load`，样式用 `clampToGround` 贴地

## 1. Entity 体系：声明式的高层封装

Cesium 的可视化 API 分两层：**Entity**（高层、声明式、面向数据）和 **Primitive**（底层、面向渲染性能，第 09 章）。日常业务 90% 用 Entity 就够了：

```js
// 一个最小实体：北京上空一个红点
const entity = viewer.entities.add({
  id: "beijing-point",      // 业务 id：供拾取/查找用（省略则自动生成）
  name: "北京",
  position: Cesium.Cartesian3.fromDegrees(116.397, 39.909, 0),
  point: {
    pixelSize: 12,
    color: Cesium.Color.RED,
    outlineColor: Cesium.Color.WHITE,
    outlineWidth: 2,
  },
});
```

要点：**一个 Entity 是一个"数据对象"，可以同时挂多种图形**——同一个位置，`point` 管点本身、`label` 管文字、`billboard` 管图标，三件套一起上就是一个完整标注：

```js
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(116.397, 39.909, 0),
  point: { pixelSize: 10, color: Cesium.Color.CYAN },
  label: {
    text: "北京 · 天安门",
    font: "14px sans-serif",
    fillColor: Cesium.Color.WHITE,
    style: Cesium.LabelStyle.FILL_AND_OUTLINE,
    outlineWidth: 2,
    outlineColor: Cesium.Color.BLACK,
    // 文字浮在点上方 20px，锚点用文字底部对齐
    pixelOffset: new Cesium.Cartesian2(0, -20),
    verticalOrigin: Cesium.VerticalOrigin.BOTTOM,
    disableDepthTestDistance: Number.POSITIVE_INFINITY, // 永远不被地形遮挡
  },
});

// 增删查
viewer.entities.remove(entity);       // 删单个
viewer.entities.removeAll();          // 删全部
const found = viewer.entities.getById("beijing-point");
```

<Callout type="must" title="必背 · Entity 三条">
1. `id` 自己起、供业务查找与拾取反查；不填 Cesium 会生成随机 id
2. 一个 Entity 可同时挂 point/label/billboard/polyline/polygon 等多种图形，各自有独立的样式块
3. `disableDepthTestDistance: Number.POSITIVE_INFINITY` 让标注永远浮在最上层——做城市标注必备
</Callout>

## 2. 线与面：贴地与拉伸

线（`polyline`）和面（`polygon`）的坐标都是 `Cartesian3` 数组，转换函数看"要不要高度"：

```js
// 线：positions 用 fromDegreesArray（[lon, lat, lon, lat, ...]，无高度）
viewer.entities.add({
  polyline: {
    positions: Cesium.Cartesian3.fromDegreesArray([
      116.39, 39.90, 116.40, 39.91, 116.42, 39.905,
    ]),
    width: 4,
    material: Cesium.Color.ORANGE,
    clampToGround: true,   // 贴地：沿线自动贴在地形/椭球面上
  },
});

// 面：hierarchy 同样用 fromDegreesArray
viewer.entities.add({
  polygon: {
    hierarchy: Cesium.Cartesian3.fromDegreesArray([
      116.38, 39.90, 116.42, 39.90, 116.42, 39.92, 116.38, 39.92,
    ]),
    material: Cesium.Color.GREEN.withAlpha(0.4),  // 半透明填充
    outline: true,
    outlineColor: Cesium.Color.GREEN,
    clampToGround: true,
  },
});
```

面的进阶玩法是**拉伸成体**：给 `extrudedHeight`（拉伸目标高度），底面在 `height`——两行代码把一块多边形变成一栋楼：

```js
viewer.entities.add({
  polygon: {
    hierarchy: Cesium.Cartesian3.fromDegreesArray([ /* ... */ ]),
    material: Cesium.Color.SANDYBROWN.withAlpha(0.9),
    extrudedHeight: 120,  // 拉到 120 米高
    height: 0,            // 底面高度
  },
});
```

<Callout type="info" title="clampToGround 的适用边界">
贴地（`clampToGround: true`）在有地形时尤其重要——不贴地的线会"穿山而过"或"悬在谷上"。但贴地渲染有额外开销：海量线面（数万条）全贴地会明显掉帧，批量场景要么不贴地，要么改用 Primitive 方案（第 09 章）。
</Callout>

## 3. GeoJSON 一次性灌入：GeoJsonDataSource

[GIS 课第 8 章](/s/gis/07)的 GeoJSON 在 Cesium 里有专门的整包加载通道——**GeoJsonDataSource**：

```js
// 直接加载 URL（也可以传 JS 对象：本地已解析的 GeoJSON）
const ds = await Cesium.GeoJsonDataSource.load("/data/beijing-districts.geojson", {
  stroke: Cesium.Color.CYAN,              // 线颜色（含面的轮廓）
  fill: Cesium.Color.CYAN.withAlpha(0.2), // 面填充
  strokeWidth: 2,
  clampToGround: true,                    // 整包贴地
});
await viewer.dataSources.add(ds);
await viewer.flyTo(ds);                   // 数据自适应缩放（第 01 章）

// 逐要素定制：遍历实体，按属性上样式
for (const entity of ds.entities.values) {
  const pop = entity.properties?.population?.getValue();
  if (pop > 3_000_000) {
    entity.polygon.material = Cesium.Color.RED.withAlpha(0.5);
  }
  // GeoJSON 的 feature properties 会挂在 entity.properties 上，
  // 拾取时直接能读——弹窗、过滤都靠它
}
```

三个关键认知：① `GeoJsonDataSource.load` 返回 **Promise\<DataSource\>**，加载完成前场景是空的；② 每个 GeoJSON feature 变成一个 Entity，其 `properties` 字段原样挂在 `entity.properties` 上，`getValue()` 取值（`time` 参数可省，默认按当前时刻求值）；③ Point 要素默认渲染成"大头针"图标，`markerColor`/`markerSymbol` 参数可以换颜色与图标。

<Callout type="warn" title="GeoJSON 高度陷阱 · clampToGround 的真实边界">
GeoJSON 坐标是 `[lng, lat, z?]`——第三个位是高度。源码级行为：`clampToGround` **只对不带 z 的要素生效**——点要素在坐标长度为 2 时才挂 `HeightReference.CLAMP_TO_GROUND`；带 z 的面会改走 `perPositionHeight`，即使配了贴地也按 z 悬浮。所以「带 z 又想贴地」的数据要先去掉 z（或逐实体设 `heightReference`）；反过来，"地下管线/飞行航迹"里 z 才是主角，别开贴地。
</Callout>

## 4. CallbackProperty：最简动画

Entity 的任何样式字段都能换成 **CallbackProperty**——每帧调用一次回调，返回值就是当帧的值。最常用的两种：

```js
// ① 呼吸点：point.pixelSize 随时间正弦变化
let start = performance.now();
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(116.397, 39.909),
  point: {
    pixelSize: new Cesium.CallbackProperty(() => {
      const t = (performance.now() - start) / 1000;
      return 10 + 4 * Math.sin(t * 3);   // 10~14 px 之间呼吸
    }, false),                            // false = 非常量，每帧求值
    color: Cesium.Color.CYAN,
  },
});

// ② 生长线：polyline.positions 每帧多一段（模拟"画线"过程）
const fullLine = Cesium.Cartesian3.fromDegreesArray([ /* 完整轨迹 */ ]);
let ratio = 0;
const growingLine = viewer.entities.add({
  polyline: {
    positions: new Cesium.CallbackProperty(() => {
      ratio = Math.min(1, ratio + 0.002);
      const n = Math.max(2, Math.floor(fullLine.length * ratio));
      return fullLine.slice(0, n);
    }, false),
    width: 3,
    material: Cesium.Color.YELLOW,
  },
});
```

原则：**能静态就静态**。CallbackProperty 每帧执行你的函数，几十个动态实体没问题，成百上千个会拖垮帧率——系统性的"时间维度"解法（CZML + Clock）是下一章的主角。

## 5. 本章小结

- Entity = 声明式可视化：一个实体挂多种图形，`id` 服务于业务查找与拾取。
- 点/标注用 point+label+billboard 三件套；`disableDepthTestDistance` 让标注永不遮挡。
- 线面贴地 `clampToGround`，面拉伸用 `extrudedHeight`；贴地有性能代价。
- GeoJSON 用 `GeoJsonDataSource.load` 整包进场景，feature properties 挂在 `entity.properties`。
- 动态样式用 `CallbackProperty`（每帧回调），能用静态就用静态。
