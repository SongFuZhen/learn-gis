## 🍼 白话版（先看这个）

> 三分钟，先懂八成；剩下的当手册查。

**这章解决什么**：GIS 文档里冒出 `d = 2R·atan2(√a, √(1−a))`，你头皮一紧——不是不会算，是不敢读。这章就干一件事：把公式还原成能念出口的话。

**一句话经验**：公式就是代码。`sin`、`cos`、`tan` 是函数调用，`λ`、`φ` 只是变量名（λ=经度，φ=纬度，`Δ`=差值）。能从左到右念出来，你就已经赢了。

**几个坑**：

- `Math.tan(30)` 算出一个巨大的负数——代码里的三角函数只吃**弧度**，30° 得先乘 `π/180`
- 拿 `atan(Δy/Δx)` 算方位，第二、三象限直接反 180°——永远用 `atan2`

**记三条**：

1. 公式 = 代码，念出声就懂
2. λ 是经度，φ 是纬度
3. 三角函数只认弧度；方向角用 atan2

## 这章讲什么

GIS 的公式和文档里全是符号：`tan(45°)`、`λ`、`Δλ`、`∑`、`√`。很多人卡在第一步——念不出来，自然也看不懂。下面把最高频的三角函数和数学符号挨个过一遍，每个都给 IPA 注音、中文谐音，再配一个 GIS 里的真实用处。看完，任何一段 GIS 公式你都能念下来。

> 读音约定：英文术语标 `/IPA/`，再给一个中文谐音当拐杖。读准了就扔掉。

## 1. 三角函数：sin、cos、tan

三角函数只回答一件事：直角三角形里，角和边长比例怎么换算。GIS 里到处是它——坡度、方位角、纬线长度、投影公式，底下全是这几个。

拿一个直角三角形说，斜边 `c`，角 θ 的对边 `a`、邻边 `b`：

```
        |\
        | \
  对边 a|  \  斜边 c
        |   \
        |____\
         邻边 b   角 θ
```

| 函数 | 写法 | 读法（IPA） | 中文谐音 | 含义 |
| --- | --- | --- | --- | --- |
| 正弦 | `sin θ` | /sɪn/ | 「赛恩」 | 对边 ÷ 斜边（a/c） |
| 余弦 | `cos θ` | /ˈkoʊsaɪn/ | 「抠-赛恩」 | 邻边 ÷ 斜边（b/c） |
| 正切 | `tan θ` | /ˈtændʒənt/ | 「坦-进特」 | 对边 ÷ 邻边（a/b） |

<Callout type="tip" title="记忆口诀">
**SOH-CAH-TOA**（读「扫-卡-图-阿」）：**S**in = **O**pposite/**H**ypotenuse，**C**os = **A**djacent/**H**ypotenuse，**T**an = **O**pposite/**A**djacent。中文记「对比斜、邻比斜、对比邻」。
</Callout>

### GIS 里怎么用

**算坡度。** 坡度角 θ 换成百分比，就是 `tan θ × 100%`。`tan 30° ≈ 0.577`，也就是 57.7%。第 11 章地形里的 slope（/sloʊp/，「斯楼普」，坡度）图层，每个像元存的就是这个。

**算纬线圈周长。** 纬度 φ 那一圈的周长 = `赤道周长 × cos φ`。北京北纬 40°，`cos 40° ≈ 0.766`，绕北京那条纬线一圈，只有赤道的 76.6% 左右。00 章说「经度一度越往北越短」，根子就在这。

**算坐标旋转。** 投影公式里的 `cos λ`、`sin φ` 还是同一套——把球面上的点转一转、摊平到图纸上。

## 2. 反三角函数：asin、acos、atan、atan2

三角函数是「角 → 比例」，反三角倒过来，「比例 → 角」。名字里的 arc-（/ɑːrk/，「阿克」）就是「把角取回来」。

| 函数 | 写法 | 读法（IPA） | 中文谐音 | 含义 |
| --- | --- | --- | --- | --- |
| 反正弦 | `asin x` 或 `arcsin x` | /ˈærsaɪn/ | 「阿斯-赛恩」 | 已知对斜比，求角 |
| 反余弦 | `acos x` 或 `arccos x` | /ˈærkoʊsaɪn/ | 「阿克-抠赛恩」 | 已知邻斜比，求角 |
| 反正切 | `atan x` 或 `arctan x` | /ˈærtæn/ | 「阿斯-坦」 | 已知对邻比，求角 |
| 双参反正切 | `atan2(y, x)` | /ˈærtæn tuː/ | 「阿斯-坦-图」 | 由 (x, y) 直接求方向角 |

<Callout type="must" title="必懂 · atan2 是 GIS 最常用的一个">
`atan2(y, x)` 吃**两个参数**（y 在前、x 在后），直接算出点 (x, y) 相对原点的方位角，**正负号已经替你处理好**，范围 −π 到 π。问「从 A 到 B 往哪走」，用的就是它（方位角 azimuth，/ˈæzɪməθ/，「艾兹-莫-斯」，下一章正式用）：

```js
const azimuth = Math.atan2(Δlng, Δlat); // 注意 y 在前
```

只写 `atan(Δy/Δx)`，第二、三象限会差 180°。新手最常踩的就是这个。
</Callout>

## 3. 度与弧度：°和 rad

一个角，两套单位：度（degree，/dɪˈɡriː/，「迪-格里」）和弧度（radian，/ˈreɪdiən/，「瑞-迪恩」）。一圈 = 360° = `2π rad`：

```
180° = π rad ≈ 3.14159 rad
1°  = π/180 ≈ 0.01745 rad
1 rad ≈ 57.3°
```

<Callout type="warn" title="最经典的坑：代码里必须用弧度">
JS 和 Python 的 `Math.sin()`、`math.cos()` **只吃弧度**。算 30° 的正切，先转：

```js
Math.tan(30 * Math.PI / 180);  // ≈ 0.577，对
Math.tan(30);                  // ≈ -6.405，错！它把 30 当成了 30 rad
```

它不报错，只是结果离谱。正切算出一个巨大的负数，先回头查单位。
</Callout>

## 4. 希腊字母速查

公式里的「外文字」多半是希腊字母（Greek letters，/ɡriːk ˈletərz/，「格里克-莱特兹」）。GIS 文档里反复出现下面这些，读音和含义都该记住：

| 符号 | 名称 | 读法（IPA） | 中文谐音 | GIS 里常表示 |
| --- | --- | --- | --- | --- |
| `π` | pi | /paɪ/ | 「派」 | 圆周率 ≈ 3.14159 |
| `λ` | lambda | /ˈlæmdə/ | 「兰姆达」 | **经度**（longitude） |
| `φ` | phi | /faɪ/ | 「法伊」 | **纬度**（latitude） |
| `Δ` | delta | /ˈdeltə/ | 「戴奥-塔」 | **差值**，如 `Δλ` = 经度差 |
| `Σ` | sigma（大写） | /ˈsɪɡmə/ | 「西格玛」 | **求和**（见第 5 节） |
| `α` | alpha | /ˈælfə/ | 「艾奥-法」 | 方位角；椭球扁率也常用它表示 |
| `β` | beta | /ˈbiːtə/ | 「比-塔」 | 第二个角/参数 |
| `θ` | theta | /ˈθiːtə/ | 「斯-塔」 | 通用的**角度**符号 |
| `ε` | epsilon | /ˈepsɪlɒn/ | 「艾普-西隆」 | 很小的**误差**量 |
| `ρ` | rho | /roʊ/ | 「柔」 | 密度；到原点的距离 |
| `γ` | gamma | /ˈɡæmə/ | 「盖奥-玛」 | 子午线收敛角（04 章） |
| `Ω` | omega（大写） | /oʊˈmeɪɡə/ | 「欧-梅-嘎」 | 角速度；经度范围 |

<Callout type="example" title="对着真实公式看一眼">
正球模型下，两点大圆距离里有个中间量 `Δσ`，读「戴奥塔-西格玛」，意思是「球面角的差」。看到希腊字母先念出来，再问它在这儿代表什么，公式立马没那么唬人。
</Callout>

## 5. 运算符号：∑、√、∫ 怎么读

| 符号 | 名称 | 读法（IPA） | 中文谐音 | 含义与用法 |
| --- | --- | --- | --- | --- |
| `+` / `−` | plus / minus | /plʌs/ / /ˈmaɪnəs/ | 「普拉-斯」/「迈-纳斯」 | 加、减 |
| `×` / `÷` | times / divided by | /taɪmz/ / /dɪˈvaɪdɪd baɪ/ | 「泰姆兹」/「迪-伐伊德-拜」 | 乘、除 |
| `=` | equals | /ˈiːkwəlz/ | 「伊-奎沃兹」 | 等于 |
| `≈` | approximately equal to | /əˈprɒksɪmətli/ | 「阿-普罗克-西姆特利」 | 约等于，GIS 换算里极常见 |
| `±` | plus or minus | /ˈplʌs ɔːr ˈmaɪnəs/ | 「普拉-斯-奥-迈-纳斯」 | 正负号，如 GPS 误差 `±5 m` |
| `√` | square root | /skwɛər ruːt/ | 「斯奎尔-鲁特」 | 平方根，距离公式 `√(x²+y²)` |
| `x²` | x squared | /skwɛərd/ | 「斯奎尔德」 | x 的平方；`x³` 读 cubed /kjuːbd/「克尤布德」 |
| `∑` | summation / sigma | /sʌˈmeɪʃən/ | 「萨-梅-申」 | 一串数**求和**：`∑hᵢ` = 所有 hᵢ 加起来 |
| `∫` | integral | /ˈɪntɪɡrəl/ | 「因-提-格罗」 | 积分（连续求和） |
| `∞` | infinity | /ɪnˈfɪnəti/ | 「因-菲-尼提」 | 无穷大 |
| `∝` | proportional to | /prəˈpɔːrʃənəl/ | 「普罗-波-申-诺」 | 正比于 |
| `∠` | angle | /ˈæŋɡl/ | 「安-戈」 | 角 |
| `°` / `′` / `″` | degree / minute / second | /dɪˈɡriː/ / /ˈmɪnɪt/ / /ˈsekənd/ | 「迪-格里」/「米尼特」/「塞肯德」 | 度 / 分 / 秒（00 章的 DMS 记法） |
| `∈` | belongs to | /bɪˈlɒŋz tuː/ | 「比-龙兹-图」 | 属于，如 `x ∈ ℝ`（x 是实数） |
| `\|x\|` | absolute value of x | /ˈæbsəluːt ˈvæljuː/ | 「艾布-索-鲁特-维奥-尤」 | 绝对值 |

<Callout type="tip" title="公式怎么念">
从左往右，见符号念名字。`d = √((x₂−x₁)² + (y₂−y₁)²)` 念作：d 等于，根号下，x 二减 x 一的平方，加，y 二减 y 一的平方。念得出来，就是真看懂了。
</Callout>

## 6. 实战：完整念一遍 haversine

<Exercise title="练习：逐符号解读大圆距离公式">
算两个经纬度点之间的球面距离，核心是 **haversine**（/ˈhævərsaɪn/，「海奥-沃尔-赛恩」）公式：

```
a = sin²(Δφ/2) + cos φ₁ · cos φ₂ · sin²(Δλ/2)
d = 2R · atan2(√a, √(1−a))
```

把它完整念出声，再说出每个符号的意思。
<ExerciseSolution>

念法：「a 等于，赛恩平方，戴奥塔-法伊除以二，加上，抠赛恩-法伊一，乘抠赛恩-法伊二，乘赛恩平方，戴奥塔-兰姆达除以二。d 等于，二乘 R，乘，阿斯坦-图，根号 a，根号下一减 a。」

符号：`φ₁、φ₂` 是两点纬度（念「法伊一、法伊二」），`Δφ` 是纬度差，`λ` 是经度，`R` 是地球半径 6371 km，`atan2` 就是第 2 节那个双参反正切。**记住所有三角函数都吃弧度**，经纬度得先乘 `π/180`。

这公式后面还会撞见：00 章算两点距离、第 13 章空间数据库的球面距离函数，都是它。

</ExerciseSolution>
</Exercise>

<Callout type="must" title="必背清单">
- **三个三角函数**：sin「赛恩」、cos「抠赛恩」、tan「坦进特」——对比斜、邻比斜、对比邻
- **一个反三角**：`atan2(y, x)`「阿斯坦-图」算方位角，y 在前
- **一个单位坑**：代码里的三角函数只吃**弧度**，度要先乘 `π/180`
- **五个高频希腊字母**：λ「兰姆达」经度、φ「法伊」纬度、Δ「戴奥塔」差值、Σ「西格玛」求和、θ「斯塔」角度
- **两个运算符**：√「斯奎尔-鲁特」、∑「萨-梅-申」
</Callout>

## 7. 本章小结

- 公式就是代码：sin/cos/tan 是函数，λ、φ、Δ 是变量名
- 三角函数只吃弧度，度数先乘 π/180
- 方位角用 atan2(y, x)，别用 atan，避免象限差 180°
- haversine 能拆成「转弧度 → 算差值 → 套公式」三段来念
