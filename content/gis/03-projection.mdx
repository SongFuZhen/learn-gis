## 本章你会学到

上一章我们把地球近似成了一个椭球（Ellipsoid，/ɪˈlɪpsɔɪd/，「伊-利普-扫伊德」），用经纬度标记位置。但手机、纸张、屏幕都是**平的**。怎么把球面上的点画到平面上？这就是**地图投影**。本章回答三个问题：为什么投影必然变形、有哪几类取舍、以及你天天在用的 Web 墨卡托（Mercator，/mərˈkeɪtər/，「默-凯-托」）到底做了什么手脚。

## 1. 为什么必须投影

经纬度是球面上的角度，可量距离、算面积、在屏幕上画地图，都需要平面。把球面"摊开"成平面的数学变换，就是投影。

问题在于：**球面没法无变形地铺平。**

<Callout type="example" title="剥不开的橘子皮">
试着把橘子皮完整地压平在桌上，它一定会裂开或被拉伸。数学上这叫球面具有非零高斯曲率（Gaussian curvature，/ˈɡaʊʃiən ˈkɜːrvətʃər/，「高欣-克-弗-彻」），而平面曲率为零，两者不可能等长对应。所以**任何投影都必然产生变形**，我们能选的只是"让哪种变形小一点"。
</Callout>

## 2. 三类取舍：保什么，牺牲什么

既然必然变形，就只能在三种"保真"目标里挑一个（或折衷）：

| 投影类型 | 保持不变 | 付出的代价 | 适合用途 |
|---|---|---|---|
| 等角（conformal，/kənˈfɔːrməl/，「肯-福-默」） | 角度、局部形状 | 面积被拉伸 | 航海、导航、Web 地图 |
| 等积（equal-area，/ˈiːkwəl ˈeəriə/，「伊-阔-艾-瑞-阿」） | 面积 | 形状被扭曲 | 人口/土地面积统计图 |
| 等距 / 折衷 | 某方向距离或综合指标 | 都不精确 | 折衷的世界地图 |

<Callout type="warn" title="没有「最好」的投影">
三者**不可兼得**。选投影时该问的第一句话永远是：**"这张图要用来做什么？"** 用来导航就保角度，用来做面积统计就保面积。拿一张等角投影的世界地图去比各国国土大小，结论就是错的。
</Callout>

<Callout type="must" title="必背 · 三类投影取舍">
- 球面高斯曲率非零、平面为零 → **任何投影必变形**，只能选牺牲哪种；
- **等角**保角度/形状，面积失真 → 航海、导航、Web 地图；
- **等积**保面积，形状扭曲 → 人口/土地面积统计图；
- **等距/折衷**保某方向距离，都不精确 → 折衷的世界地图；
- 三者**不可兼得**：先问"这张图要用来做什么"，再选投影。
</Callout>

## 3. 投影家族：按「怎么铺」分类

上一节回答了"保什么"，这一节回答"怎么铺"。所有投影都可以想象成把一个**可展开的面**（圆柱、圆锥、平面）贴在地球上，把点投到面上再展开。按构造面分三大家族：

| 家族 | 构造面 | 变形最小的地方 | 典型用途 |
|---|---|---|---|
| 圆柱投影 | 圆柱侧面包住地球 | 赤道带 | 墨卡托、Web 墨卡托、UTM（/ˌjuː tiː ˈɛm/，「尤-提-艾姆」；横轴） |
| 圆锥投影 | 圆锥罩住地球 | 所贴的纬线附近 | 中纬度国家/大洲地图（Albers，/ˈælbərz/，「阿尔-伯兹」；Lambert，/ˈlæmbərt/，「兰-伯特」） |
| 方位投影 | 平面在某点相切 | 切点附近 | 极地图、半球图、航线图 |

再按**投影面的姿态**细分：圆柱可以正放（赤道处最准）也可以横放（某条中央经线最准，UTM/高斯-克吕格就是横轴圆柱）；还可以**相切**（贴一点/一线）或**相割**（切两线，把变形摊得更匀）。

<Callout type="example" title="三个常见投影小传">
- **Albers 等积圆锥**：两条标准纬线相割、保面积。中国全图、美国全国图常用它画土地利用/人口密度这类"看面积"的专题图。
- **方位等距**（Azimuthal Equidistant，/ˌæzɪˈmʌðəl ˌɛkwɪˈdɪstənt/，「阿-兹-马-瑟-艾-奎-迪-斯坦特」）：从中心点向任何方向**距离和方向都保真**，联合国会徽用的就是以北极为中心的方位等距投影；飞行航线图也爱用它。
- **Mollweide / Gall-Peters 等积世界投影**（Mollweide，/ˈmɒlvaɪdə/，「莫-瓦伊德」；Gall-Peters，/ɡɔːl ˈpiːtərz/，「高尔-彼得斯」）：世界地图要"比面积"（人口分布、气候带）时用它，形状被压扁。这正是对墨卡托"格陵兰骗局"的纠正。
</Callout>

<Callout type="must" title="必背 · 家族与场景速配">
- 圆柱 → 赤道附近、航海与 Web 地图（正轴）；**横轴圆柱 = UTM/高斯-克吕格**（第 04 章）
- 圆锥 → 中纬度国家/大洲，**Albers 保面积**做专题统计图
- 方位 → 极地、半球、以某点为中心的航线图，**方位等距保中心向距离**
- 同一家族里再选"保什么"：家族管"哪里变形小"，等角/等积管"牺牲什么"
</Callout>

  tool="calc"
  title="练习：给三张图选投影"
>
  只用本节知识，给下面三种用途各挑一个合适的投影家族 + 保真类型，并说一句理由：

  1. 一张印度尼西亚（横跨赤道）的人口密度专题图；
  2. 一张南极科考站的航线示意（以南极点为中心）；
  3. 一张供水手沿固定罗盘方向航行的海图。

  <ExerciseSolution>
    1. 印尼横跨赤道 → **正轴圆柱 + 等积**（如 Albers 不适合赤道国家，可用等积圆柱）；专题图优先保面积。
    2. 以南极点为中心 → **方位投影 + 等距或等角**；极地是方位投影的主场。
    3. 海图 → **等角圆柱（墨卡托）**；恒向线（loxodrome，/ˈlɒksədroʊm/，「洛克-索-德罗姆」）是直线，保角度才能按罗盘航行。
  </ExerciseSolution>
</Exercise>

<Exercise
  tool="calc"
  title="练习：算北纬 45° 处墨卡托的面积夸大"
>
  提示：经线放大率 = 1/cos φ，面积按两个方向的放大率相乘。cos 45° ≈ 0.7071。

  <ExerciseSolution>
    经线放大率 = 1/0.7071 ≈ **1.414 倍**；纬线方向同样放大 1.414 倍，
    面积放大率 = 1.414² ≈ **2 倍**。

    对照记忆：60° 面积 ×4、70° 面积 ×8.5、45° 面积 ×2，纬度越高越离谱，中纬度就已经不可忽略。
  </ExerciseSolution>
</Exercise>

## 4. 墨卡托：航海家的选择

最出名的投影是**墨卡托投影**（1569 年）。它是一种等角圆柱投影：假想把地球装进一个圆柱，把球面上的点"投"到圆柱面上，再展开。

它最大的优点是**恒向线（loxodrome）是直线**：保持固定罗盘方位角的航线，在墨卡托图上是一条直线。对航海太有用了，所以它统治了航海图几百年。

代价是**高纬度面积被急剧放大**。它的纵坐标公式是：

```
y = R · ln( tan( π/4 + φ/2 ) )
经线方向放大率 = 1 / cos φ
```

<Callout type="example" title="动手算一遍：北纬 60° 的纵坐标">
取 R = 6 371 000 m、φ = 60°，把公式一步步代进去：

1. `π/4 + φ/2` = 45° + 30° = 75°；
2. tan 75° ≈ 3.732；
3. ln 3.732 ≈ 1.317；
4. y = 6 371 000 × 1.317 ≈ **8 390 000 m ≈ 8 390 km**（赤道处 y = 0，纬度越高 y 涨得越快）；
5. 该纬度经线放大率 = 1/cos 60° = **2 倍**，面积则被放大约 2² = **4 倍**。
</Callout>

<Callout type="example" title="格陵兰骗局">
在墨卡托世界地图上，格陵兰（约 216 万 km²）看起来和非洲（约 3022 万 km²）差不多大，实际上非洲是它的 **14 倍**。因为格陵兰在高纬度，面积被放大了好几倍。北纬 70° 处，面积放大倍数约为 `1/cos²70° ≈ 8.5` 倍。
</Callout>

<Callout type="must" title="必背 · 墨卡托三件事">
- **恒向线（保持固定罗盘方位角的航线）是直线**，这是它统治航海图几百年的原因；
- 经线放大率 = **1/cos φ**，纬度越高放大越狠；
- 面积放大率 = **1/cos² φ**，北纬 70° 约 **8.5 倍**，高纬陆地看起来"虚胖"。
</Callout>

## 5. Web 墨卡托：互联网地图的"偷工减料"

你刷的每一个在线地图（高德、百度、Google、OpenStreetMap），用的几乎都是**Web 墨卡托（EPSG:3857）**。它在墨卡托基础上又偷了一步懒：

<Callout type="info" title="Web 墨卡托 = 把地球当正球做墨卡托">
严格的墨卡托应该用椭球计算。但为了省事，Web 墨卡托直接把地球当成**半径 6 378 137 m 的正球体**再做墨卡托。这样瓦片金字塔的坐标换算可以用简单的整数运算，快。代价是它和严格的椭球墨卡托之间有**几十米级的偏差**，对显示无所谓，对精密测量不行。
</Callout>

Web 墨卡托对整个地球做了三件事：

- 把全球投影成**一个正方形**，x、y 都在 ±20037508.34 m 之间；
- 按"四叉树"把正方形切成一层层瓦片，这就是第 07 章要讲的瓦片金字塔；
- 选正方形、选等角，全是为了**前端快速拼图**，不是为了精确。

<Callout type="example" title="20 037 508 这个数是哪来的">
正方形的半边长不是拍脑袋定的，一步就能推出来：

1. 正球半径 R = 6 378 137 m；
2. 赤道周长 = 2πR ≈ 40 075 017 m；
3. 赤道在图上被拉成正方形的一条边，所以半边长 = πR = 3.14159 × 6 378 137 ≈ **20 037 508 m**。

于是经度 ±180° 恰好对应 x = ±20 037 508.34 m，正方形左右两条边正好"贴上"地球一圈。
</Callout>

<Callout type="must" title="必背 · Web 墨卡托关键数字">
- 编号 **EPSG:3857**，坐标单位是**米**；
- 地球被当成**正球体**，半径 **6 378 137 m**；
- 平面范围 x、y ∈ **±20 037 508.34 m**；
- 与严格椭球墨卡托偏差**几十米级**：显示够用，精密测量不行。
</Callout>

## 6. 一个最常踩的坑

<Callout type="warn" title="EPSG:4326 和 EPSG:3857 混用">
- 把 `3857` 的米数当经纬度传给地图库 → 要素跑到南极之外；
- 反过来把经纬度当米数画 → 所有要素挤在原点附近一个像素里；
- 在 `3857` 的图上直接量距离/面积 → 高纬度结果严重偏大。

记住：**4326 单位是度（经纬度），3857 单位是米（平面）**。两者之间的转换就是投影/反投影。
</Callout>

<Callout type="example" title="同一个北京，两套坐标">
北京（东经 116.4°，北纬 39.9°）在两套坐标系下的数值完全不同：

- **EPSG:4326**：`(116.4, 39.9)`，单位是度；
- **EPSG:3857**：`(约 12 957 600, 约 4 851 000)`，单位是米。

混用的后果：把 3857 的 `(12957600, 4851000)` 当经纬度传给地图库，"东经 1295 万度"早飞出地球；把 `(116.4, 39.9)` 当米画，距原点只有一百多米，所有要素挤成原点旁的一个像素。
</Callout>

<Callout type="must" title="必背 · 4326 vs 3857">
- **4326 = 度（经纬度）**，**3857 = 米（平面）**，先看单位再喂给地图库；
- 米当度 → 要素跑到南极之外；度当米 → 全挤在原点一个像素里；
- 在 3857 的图上直接量距离/面积 → 高纬度结果**严重偏大**；
- 两者之间的转换 = **投影/反投影**。
</Callout>

## 7. 本章回顾

<Callout type="tip" title="三句话记住投影">
1. 球面铺平必然变形，投影是"选哪种变形"的取舍；
2. 等角保形状、等积保面积、等距保某方向距离，**按用途选**；
3. Web 墨卡托（3857）是为快速拼图做的正球近似，显示好用，**别在上面量距离和面积**。
</Callout>
